🎬 Emby

L'adresse de ton serveur Emby et sa clé API (Emby → Tableau de bord → Clés API). Emby sera prévenu pour rafraîchir le dossier d'un groupe après un rangement (pas encore utilisé).

📁 Dossier des clips

Le dossier « Video clip » de ta médiathèque Emby : un sous-dossier par groupe. Il n'est que lu pour l'instant.

🔊 Volume des clips

Même réglage que les thèmes de MouFlopening : chaque clip est ramené au même niveau (ReplayGain, 89 dB = référence). Tes clips actuels sont à 90 dB environ. Seule la piste audio est refaite (AAC) ; l'image n'est jamais réencodée.

🖼️ fanart.tv

Pour de belles images de groupe (logo, bannière, fonds, pochettes d'album, cdart) en plus de TheAudioDB. Clé personnelle gratuite : fanart.tv → ton compte → « Personal API Key ».

🎵 TheAudioDB (facultatif)

Biographie en français et images de groupe. Sans clé personnelle, la clé publique de test est utilisée (suffisant pour un usage normal).

🎞️ IMVDb (en attente)

Base de clips vidéo. Leur recherche est coupée pour l'instant : la clé est gardée pour quand elle reviendra.

🍪 Cookies YouTube

Pour lire (puis télécharger) les formats réservés au compte Premium. Le contenu n'est jamais affiché, ni envoyé sur GitHub, ni écrit dans le Journal.
Comment obtenir le fichier ?
  1. Dans ton navigateur, connecte-toi à youtube.com avec le compte Premium.
  2. Installe une extension d'export de cookies, par exemple « Get cookies.txt LOCALLY ».
  3. Sur la page youtube.com, exporte au format Netscape (fichier cookies.txt).
  4. Ouvre le fichier avec un éditeur de texte, copie tout et colle-le ci-dessous.

🧰 Outils du serveur

yt-dlp lit YouTube ; deno et son script de défi sont nécessaires pour voir tous les formats ; ffmpeg servira à vérifier les fichiers.
